# Turning away and leaving

- The eyes lead, then the head, then the body: in the inbetweens the head is already turned while the shoulders
  are still on the way.
- The view changes (three-quarter right → profile → back) are separate drawings; each inbetween names the view
  it is in.
- A character with text on their clothes must not be mirrored; turning them is done with drawings, not by flipping.
- The exit itself can be a cut or the character walking out of the frame; say which in the description.
